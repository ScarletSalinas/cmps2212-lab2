# CMPS2212 GUI Programming
## Lab #2: DOM Selection and Event Handling

### Lab Description
Lab 2 focuses on DOM manipulation and event handling through methods like getElementById and querySelector. 
It focusses on attaching event listeners, updating element content, and using browser Developer Tools for debugging.
